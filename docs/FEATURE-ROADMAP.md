# 功能路线图

## 现状概览

当前版本已覆盖 MongoDB 图形客户端的高频核心场景：

| 能力 | 状态 |
| --- | --- |
| 可视化查询构建器（VQB） | ✓ 已内置 |
| 8 语言 Query Code 生成 | ✓ 已内置 |
| SQL 查询（GROUP BY 聚合翻译） | ✓ 已内置 |
| 虚拟化网格 + BSON 着色 | ✓ 已内置 |
| 多连接 / 导航树 | ✓ 已内置 |
| Schema 分析（采样推断） | ✓ 已内置 |
| CRUD 编辑 / 集合 / 索引管理 | ✓ 已内置 |
| 导入导出 | 二期 |
| 聚合管道构建器 | 三期 |
| 数据对比 / 同步 / 备份 | 四期 |

## 已交付（一期 MVP + 二期 + SQL 查询）

- 连接管理与三级懒加载树（类型徽标、本地过滤）
- 查询栏：Monaco filter + projection / sort / skip / limit，耗时与总数反馈；JSON / SQL 双模式
- VQB：27 操作符 + 递归组 + Include 排除 + 类型过滤 + 双向同步
- SQL 查询：MySQL 语法子集 → find / aggregate 双形态翻译；GROUP BY 聚合；单行 / 选中 / 全部三种执行
- Query Code：8 语言实时生成、一键复制
- 结果区：虚拟化表格 / JSON 双视图 / 类型着色 / 节点折叠 / 明细弹窗（上下条导航）/ 分页 / mongosh 风格输出
- 文档 CRUD（插入 / 编辑 / 删除）、集合管理（创建含时间序列与聚簇 / 重命名 / 删除）、索引管理（列表 / 创建 / 删除）
- 通栏状态栏、日间 / 夜间双主题
- 测试：155 项 vitest（core 语义 + SQL 翻译 + 冒烟辅助）

## 二期收尾（下一批）

- 导入导出：JSON / CSV / EJSON，含字段映射
- 视图创建 / 用户与角色基础视图
- 连接增强：SSH 隧道、TLS、副本集拓扑显示
- 查询历史与收藏

## 三期（深度分析）

- 聚合管道构建器（阶段卡片 + 拖拽 + 预览）
- Explain 可视化（PLANSTAGE 树、索引命中标注）
- 性能面板：慢查询列表、实时操作图表
- Schema 验证规则编辑器

## 四期（团队/运维）

- 数据对比与同步（集合级 diff → 定向迁移脚本）
- 备份快照与恢复调度
- 内嵌 mongosh 终端
- 多窗口 / 工作区配置云同步
